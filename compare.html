Using them together

# Gemfile
gem "respondo"
gem "respondo-graphql"
gem "respondo-grpc"

Each gem keeps its own configuration: Respondo.configure does not affect GraphQL responses, and RespondoGraphql.configure does not affect JSON ones. Helper names never collide as long as you use the prefixed names. See the note on short names.

Same codes everywhere

The names and numeric codes match across all three gems, so meta.code / extensions.code means the same thing in every envelope: 200 is OK, 404 is not found, 422 is unprocessable.
